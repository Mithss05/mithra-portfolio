# Mithra B — Animated Developer Portfolio

A responsive, single-page portfolio built with HTML, CSS and JavaScript. No build tools are required.

## Features
- Dark, modern design with purple/cyan accents
- Scroll reveal animations and animated hero code window
- Responsive mobile navigation
- Animated project visuals and scroll progress indicator
- Sections for About, Skills, Projects, Experience, Education, Certifications and Contact
- Reduced-motion accessibility support

## Run locally
Open `index.html` in your browser, or use the VS Code Live Server extension.

## Publish using GitHub Pages
1. Create a public GitHub repository named `mithra-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then Save.
6. Your site should appear at `https://Mithss05.github.io/mithra-portfolio/` after deployment.

## Personalize before publishing
- Confirm the education status and CGPA text are current.
- Replace GitHub profile links on project cards with direct repository URLs when available.
- Add a resume PDF if you want a downloadable resume button.
- Review all project descriptions for accuracy and only add metrics you can verify.
